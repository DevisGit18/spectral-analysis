Calibration Modelling : 3 analytes completed 

This project builds a handheld device that reads paper-based colour-change tests for three liver biomarkers using an 11-channel spectral sensor (AS7341).
My role is the computational side: converting raw sensor colour readings into accurate concentration values through mathematical calibration models.
My contribution is data processing, curve fitting, statistical model selection, and validation.
Approach: test multiple candidate mathematical models per analyte, select the best one using a statistical criterion (AIC) rather than R² alone, and verify the result is reproducible.
